Releases

Every release of snapfit publishes its own frozen edition of The Snapfit Book, with every example compiled and verified as a release gate. Pick the version your project uses to read its book.

Releases

snapfit v0.3.0

Released on 2026-11-26

Static dispatch: a trait marked once with #[snapfit::static_dispatch] is dispatched through a match over a closed list of its implementations, each field naming the one it holds, instead of through a trait object.

Read The Snapfit Book (v0.3.0) · Release notes on GitHub (v0.3.0)

snapfit v0.2.0

Released on 2026-11-23

Fields typed as their trait, Arc<dyn Trait>, built from the implementation they name, and fields whose construction can fail, built by a try_new() that returns the first error.

Read The Snapfit Book (v0.2.0) · Release notes on GitHub (v0.2.0)

snapfit v0.1.1

Released on 2026-11-18

The same API as 0.1.0, documented for users: docs.rs shows the README and documents the container macro and the Container trait, and the README on crates.io leaves out the unstable and planned APIs and links to every edition of the book.

Read The Snapfit Book (v0.1.1) · Release notes on GitHub (v0.1.1)

snapfit v0.1.0

Released on 2026-11-18

Compile-time verified dependency injection with pure-Rust domain types: singletons wired by name, each built with its constructor, Default, a factory or its type's builder, and unknown dependencies and cycles reported at compile time.

Read The Snapfit Book (v0.1.0) · Release notes on GitHub (v0.1.0)
