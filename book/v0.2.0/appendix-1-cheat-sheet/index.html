Cheat sheet

Every container attribute and field attribute in snapfit 0.2, with a link to the chapter that teaches it.

Container attributes (#[container(...)])

Declaration What it does Taught in
#[container] Keeps the struct as written (attributes, docs, visibility), builds each field after the fields it needs, and generates new(), Default, Container, and get_<name>() methods; with a fallible field, try_new() and FallibleContainer instead of new(), Default and Container. Chapter 5, Chapter 13
#[container(leaf_build = default)] Builds every field with no deps and no build of its own with Default; a field's own build always wins. Without it, such fields call new(). A fallible field can't be one of them: give it a build of its own. Chapter 7, Chapter 13
#[container(leaf_build = constructor(<fn>))] Builds those same fields with <Type>::<fn>(); constructor(new) is what a container does without leaf_build. Unless <fn> is new, a fallible field can't be one of them. Chapter 7

Ways to build a field (build = ...)

build What the container calls Choose it when Taught in
Left out <Type>::new(...), with the fields in deps in the order they are listed; for a leaf, whatever the container's leaf_build says. The type has a new whose arguments can't be passed the wrong way round. Chapter 7
build = default <Type>::default(); no deps allowed, and the field can't be fallible. The type derives Default and needs nothing. Chapter 7
build = constructor(<fn>) <Type>::<fn>(...), with the fields in deps in the order they are listed. The type's constructor has another name. Chapter 7
build = builder <Type>::builder(), one setter for each name in deps, then .build(), or the start and finish it names. The type has a builder, or can have one, such as when two of its inputs have the same type. Chapter 10
build = factory build_<field> of <Container>Factories, which you write, with the inputs by name; not beside implementation. Building the field is the container's business, or the type isn't yours. Chapter 10, Chapter 11

A leaf is a field with no deps and no build of its own. leaf_build sets how every leaf of a container is built, new when it is left out, and a field's own build always wins. A fallible field can't be a leaf that leaf_build builds, unless that is constructor(new).

Field attributes

Declaration Storage Construction call Taught in
#[singleton] Stored in container; cloned on get_<name>(). <Type>::new() (auto-wrapped in Arc::new(...) if field type is Arc<T>). Chapter 5
#[singleton(deps = [a, b])] Stored in container; cloned on get_<name>(). <Type>::new(a.clone(), b.clone()). Chapter 7
#[singleton(build = default)] Stored in container; cloned on get_<name>(). <Type>::default(); no deps allowed. Chapter 7
#[singleton(deps = [a], build = constructor(from_a))] Stored in container; cloned on get_<name>(). <Type>::from_a(a.clone()). Chapter 7
#[singleton(deps = [a, b], build = factory)] Stored in container; cloned on get_<name>(). <Container>Factories::build_<name>(<Container><Name>Inputs { a: a.clone(), b: b.clone() }), which you implement; the field may be a trait object. Chapter 10, Chapter 11
#[singleton(deps = [a], implementation = StripeGateway)] on Arc<dyn Trait> Stored in container as declared; cloned on get_<name>(). Arc::new(<StripeGateway>::new(a.clone())), converted to the trait object; build = constructor(...), default and builder work on StripeGateway. The getter and every dependent see Arc<dyn Trait>. Chapter 11
#[singleton(deps = [a, label = b], build = builder)] Stored in container; cloned on get_<name>(). <Type>::builder().a(a.clone()).label(b.clone()).build(). Chapter 10
#[singleton(deps = [a], build = builder(start = make, finish = done))] Stored in container; cloned on get_<name>(). <Type>::make().a(a.clone()).done(). Chapter 10
#[singleton(deps = [a], fallible = true, build = constructor(connect))] Stored in container; cloned on get_<name>(). <Type>::connect(a.clone()), which returns a Result; its error becomes the snapfit::BuildError that try_new() returns. Works with new, a named constructor, a builder and a factory, whose build_<name> then returns Result<FieldType, Box<dyn Error + Send + Sync>>. Chapter 13
