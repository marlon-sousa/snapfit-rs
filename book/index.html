The Snapfit Book

snapfit is a compile-time verified dependency injection framework for Rust that keeps your domain types 100% free of framework macros and traits. This book shows you how to build with it, one small online shop at a time.

Every code listing in the book is extracted from a complete Rust program in the repository that compiles and runs as a release gate, with its recorded output shown directly underneath.

Pick a release edition

  • The Snapfit Book (v0.3.0)Published 2026-11-26 — Static dispatch: a trait marked once with #[snapfit::static_dispatch] is dispatched through a match over a closed list of its implementations, each field naming the one it holds, instead of through a trait object.
  • The Snapfit Book (v0.2.0)Published 2026-11-23 — Fields typed as their trait, Arc<dyn Trait>, built from the implementation they name, and fields whose construction can fail, built by a try_new() that returns the first error.
  • The Snapfit Book (v0.1.1)Published 2026-11-18 — The same API as 0.1.0, documented for users: docs.rs shows the README and documents the container macro and the Container trait, and the README on crates.io leaves out the unstable and planned APIs and links to every edition of the book.
  • The Snapfit Book (v0.1.0)Published 2026-11-18 — Compile-time verified dependency injection with pure-Rust domain types: singletons wired by name, each built with its constructor, Default, a factory or its type's builder, and unknown dependencies and cycles reported at compile time.
